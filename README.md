# Ricau Avocat : les deux propositions (prototype de travail)

Aperçu de travail de l'agence pour la refonte du site de Me Julie Ricau. Non indexé, ne pas diffuser.

- `actuel/` : le site actuel refait à l'identique (28 pages), polices libres.
- `refonte/` : la refonte proposée (6 pages pour l'instant).
- En bas de chaque page, le sélecteur « À l'identique | Refonte » ouvre la même page dans l'autre proposition.

Le formulaire de contact de `actuel/contact--rdv.html` est le vrai formulaire de la cliente : ne pas l'envoyer pour tester.
